## Cancellation request window

A cancellation may be requested within 30 minutes after order placement, but only
while the order has not entered warehouse picking. The request can be submitted
from Order history using Cancel order. The order's actual status is account
specific and must be checked in the account; a general policy answer cannot
confirm that a particular order can still be stopped.

Submitting a cancellation request is not confirmation that it succeeded. If
Order history no longer offers the cancellation action, the warehouse may have
started picking. Contact support promptly, but cancellation cannot be guaranteed
after picking begins. If the parcel has shipped, it cannot be cancelled or
edited; use the return rules after delivery if the item is eligible.

## Address, item, and quantity changes

The delivery address, shipping service, payment method, item selection, size,
color, and quantity cannot be edited after order submission. During the
30-minute pre-picking window, request cancellation and, if it succeeds, place a
new order with the correct details. A new order can have a different price,
stock availability, promotion eligibility, and delivery estimate.

Changing the address directly with a carrier is not a Pine & Peak order edit and
is not guaranteed. Never send a full card number, security code, or password to
request a change.

## Partial cancellation and promotions

An order can be cancelled only as a whole through the self-service cancellation
action. We cannot promise that an individual line can be removed while other
items continue processing. If the order has already been dispatched, refusing
the parcel is not a substitute for an approved return and may delay resolution.

A replacement order is evaluated under current prices and promotions. A
promotion on the original order is not automatically transferred, and a
cancelled order cannot be restored after cancellation is confirmed.

## When status-specific help is needed

To determine whether the 30-minute request window is still open or picking has
begun, support must look up the order. The policy describes the rule but does not
provide access to order status or perform cancellation.
